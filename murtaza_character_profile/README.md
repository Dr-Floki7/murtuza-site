# Murtaza AI Character Profile

This folder contains the reusable identity information for generating a consistent AI version of Murtaza across images and videos.

## Files
- `CHARACTER_BIBLE.md` — master identity and appearance profile
- `IDENTITY_LOCK.md` — details that must remain consistent
- `SHOT_PROMPT_TEMPLATE.md` — reusable prompt structure for every shot
- `NEGATIVE_PROMPT.md` — common consistency failure prevention
- `REFERENCE_ASSET_CHECKLIST.md` — recommended reference images and future updates

## Usage
1. Keep the character identity details unchanged.
2. Add only scene-specific information to the shot prompt.
3. Attach the best available reference images whenever the generation tool supports image references.
4. Review every output for face, hair, beard, nose, eyes, body proportions, and unwanted changes.
5. If a new appearance is intentional, save it as a separate approved variant rather than overwriting the master profile.

## Important
This is a visual likeness profile based only on the supplied photos. It does not infer private attributes, personality, age, height, or other facts that are not reliably visible.
