# NEGATIVE PROMPT — MURTAZA

Use when supported by the image or video generation tool.

## Identity errors
- Different person
- Generic male model
- Unrecognizable face
- Face replacement
- Altered facial proportions
- Slimmed or beautified face
- Narrower nose
- Different nose profile
- Different eye shape
- Altered eye color
- Different beard style
- Clean-shaven face
- Thin beard
- Missing chin beard
- Completely different haircut
- Long hair
- Slicked-back hair
- Unnatural hairline

## Rendering errors
- Plastic skin
- Excessive skin smoothing
- Beauty filter
- Over-sharpened face
- Unrealistic beard strands
- Wax-like skin
- Cartoon face
- Anime face
- CGI-looking human
- Unnatural facial symmetry
- Distorted anatomy
- Extra fingers
- Deformed hands
- Duplicate person
- Floating objects
- Text
- Watermark
- Logo
